# Citation and licence

## Relationship to DeFoG

The base model follows the upstream [DeFoG](https://github.com/qym7/DeFoG) implementation (Qin, Madeira, Thanou,
Frossard; ICML 2025). Everything built on top of it here was developed in a research fork. This package is **not
affiliated with or endorsed by the DeFoG authors**.
[NOTICE](https://github.com/aimat-lab/defog-adapt/blob/main/NOTICE) lists the full credits and the papers behind each
method.

## Citing
